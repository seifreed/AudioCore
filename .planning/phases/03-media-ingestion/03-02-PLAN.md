Create src/audiocore/media/extractor.py with extract_audio() function:

1. Function signature:
   ```python
   def extract_audio(
       input_path: Path,
       output_path: Path | None = None,
       start_time: float | None = None,
       duration: float | None = None,
       ffmpeg_path: str = "ffmpeg",
       timeout: float = 3600.0,
       progress_callback: Callable[[float], None] | None = None,
   ) -> Path:
   ```

2. Implementation:
   - If output_path is None, create temp file with NamedTemporaryFile(suffix=".wav", delete=False)
   - Validate input file exists (use InvalidInputError)
   - If progress_callback is provided, call probe() to get total duration
   - Build ffmpeg command:
     - `["ffmpeg", "-y"]` (overwrite output)
     - If start_time: `["-ss", str(start_time)]` (before -i for fast seeking)
     - `["-i", str(input_path)]`
     - If duration: `["-t", str(duration)]`
     - `["-ar", "16000"]` (16kHz sample rate)
     - `["-ac", "1"]` (mono)
     - `["-c:a", "pcm_s16le"]` (lossless PCM)
     - `[str(output_path)]`
   - Run subprocess with timeout
   - Parse ffmpeg stderr for progress (time= field) when progress_callback provided
   - Call progress_callback with percentage (current_time / total_duration * 100)
   - Validate output file exists and has content
   - Return output_path

3. Error handling:
   - FileNotFoundError -> MediaError with "ffmpeg not found" message
   - subprocess.TimeoutExpired -> MediaError with timeout message
   - returncode != 0 -> MediaError with stderr in context
   - Output file missing/empty -> MediaError with extraction failure message

4. Add helper function:
   - `_build_ffmpeg_command(...) -> list[str]`: Build command from parameters
   - `_validate_output(output_path: Path) -> None`: Ensure output exists and has content
   - `_parse_progress(stderr_line: str, total_duration: float) -> float | None`: Parse ffmpeg stderr for progress percentage

### Task 2: Add cleanup context manager

<action>
Add a context manager for temporary file cleanup to src/audiocore/media/extractor.py:

```python
from contextlib import contextmanager

@contextmanager
def temp_audio_file(suffix: str = ".wav"):
    \"\"\"Create temporary audio file with automatic cleanup.
    
    Usage:
        with temp_audio_file() as temp_path:
            extract_audio(input_path, temp_path)
            # Process temp_path
        # File automatically deleted after context
    \"\"\"
    from tempfile import NamedTemporaryFile
    temp = NamedTemporaryFile(suffix=suffix, delete=False)
    temp_path = Path(temp.name)
    temp.close()
    try:
        yield temp_path
    finally:
        temp_path.unlink(missing_ok=True)
```

Also add to src/audiocore/media/__init__.py exports.
</action>
