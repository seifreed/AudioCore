Create src/audiocore/media/probe.py with probe() function:

1. Create src/audiocore/media/__init__.py (empty, exports added in Task 3)

2. Create src/audiocore/media/probe.py:
   - probe(file_path: Path, ffprobe_path: str = "ffprobe") -> MediaInfo
   - Use subprocess.run() with capture_output=True, text=True, timeout=30
   - Build ffprobe command: ["ffprobe", "-v", "quiet", "-print_format", "json", "-show_format", "-show_streams", str(file_path)]
   - Parse JSON output with json.loads()
   - Extract: duration (format.duration or calculate from streams), format (format.format_name), codec (audio stream codec), sample_rate, channels
   - Handle errors: FileNotFoundError (ffprobe not found), subprocess.TimeoutExpired, json.JSONDecodeError, missing fields
   - Return MediaInfo model with extracted data

3. Add validation helper:
   - _validate_file_exists(file_path: Path) -> None: raises InvalidInputError if file not found
   - _check_ffprobe_available(ffprobe_path: str) -> None: raises MediaError if ffprobe not found
