### Task 2: Implement environment variable loading with SecretStr

<name>Implement environment variable loading with SecretStr</name>
<files>
- src/audiocore/config/settings.py
</files>
<action>
Verify environment variable loading works:
- AUDIOCORE_OPENAI_API_KEY -> openai_api_key (SecretStr)
- AUDIOCORE_BACKEND -> backend (BackendType enum)
- AUDIOCORE_MODEL -> model_size (ModelSize enum)
- AUDIOCORE_LANGUAGE -> language (str | None)
- AUDIOCORE_OUTPUT_FORMAT -> output_format (OutputFormat enum)
- AUDIOCORE_BACKEND_PREFERENCE -> backend_preference (SelectionPolicy enum)

Ensure:
- SecretStr masks API key in str() and repr()
- Environment variables are case-insensitive (handled by BaseSettings)
- Invalid enum values raise ValidationError with helpful message
</action>
<verify>
<automated>python -c "
import os
os.environ['AUDIOCORE_BACKEND'] = 'openai'
os.environ['AUDIOCORE_MODEL'] = 'large'
os.environ['AUDIOCORE_OPENAI_API_KEY'] = 'sk-test-secret'

from audiocore.config.settings import AppConfig
from audiocore.types import BackendType, ModelSize

config = AppConfig()
assert config.backend == BackendType.OPENAI
assert config.model_size == ModelSize.LARGE
# Verify SecretStr masking
assert 'sk-test-secret' not in str(config)
assert 'sk-test-secret' not in repr(config)
print('Environment variable loading verified')
"</automated>
</verify>
